# Post-Harvest & Storage

Produce lost after harvest — to poor storage, slow drying, pests, or a
badly-planned pickup — never shows up in a yield record. This is where you
track what happens between harvesting and selling.

## Logging storage details

On the **Yields** page, each harvest record now has a **Storage** button
next to Edit/Delete. Click it to record:

- **Storage location** — which shed, store, or rented space
- **Drying method** and **drying date** — sun-dried, crib, tarpaulin, etc.
- **Quality grade** — A / B / C / reject, if you're grading
- **Expected loss** — how much you expect to lose to spoilage, pests, or
  spillage, and why

Once saved, the button turns into a green **Stored** badge so you can see
at a glance which harvests still need this logged.

You don't have to fill in every field — record what's useful and leave the
rest blank.

## Reminder

If a harvest sits for a while without a storage record, you'll see a
**Log storage details** notification — a nudge, not a requirement.

## Collection & transport on a sale

When you record a sale from **Inventory → Sell**, you can now note:

- **Collection point** — where the buyer picks it up
- **Transport** — your truck, the buyer's pickup, a courier, etc.
- **Pickup date**

These show up under the buyer's name in that item's sale history — handy
when you're coordinating several pickups at once.
